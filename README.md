# About

**Morok** is a narrative-driven psychological horror game set in rural England during the 1980s.

After moving into an old countryside house, twelve-year-old Jack discovers a broken radio in the attic. Once repaired, someone answers.

The voice has forgotten its own name.

But it remembers his.

---

# Features

- Atmospheric psychological horror
- Story-driven exploration
- Two parallel worlds
- Multiple endings
- Environmental storytelling
- Original soundtracks
- Fully voiced dialogues
